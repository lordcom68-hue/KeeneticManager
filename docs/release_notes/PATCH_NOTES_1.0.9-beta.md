# Keenetic Manager 1.0.9-beta

Стабильная контрольная точка в ходе разработки, расширяющая безопасную
самопроверку роутера историей и сравнением результатов.

## Возможности

- хранение последних десяти обезличенных результатов для каждого роутера;
- постоянное отображение даты и результата последней проверки;
- выделение новых, устранённых и изменившихся проблем;
- просмотр сохранённой истории в одном окне;
- повтор только пунктов с предупреждениями и ошибками;
- добавление истории в диагностический архив;
- устранение лишнего полного обновления после read-only действий.

## Безопасность

История не содержит имени роутера, сетевых адресов и учётных данных. Повтор
проблемных пунктов использует те же команды только для чтения и не изменяет
конфигурацию KeeneticOS.
