# Keenetic Manager 0.35.8

- Фактический статус Wi-Fi строится по show/interface, а MWS-состояние хранится отдельно.
- Короткий mws.wlan toggle получает безопасный fallback полным сохранённым профилем.
- Связанные AccessPoint синхронизируются через проверенный /rci/interface/up|down, а не CLI parse.
- Диагностика toggle содержит saved/fallback/physical результаты.
- Добавлена явная индикация рассинхронизации MWS и физических точек доступа.
- Схема базы остаётся 280.
