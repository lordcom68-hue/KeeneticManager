# Keenetic Manager 1.0.2-beta

Техническая стабильная версия в ходе разработки. Пользовательская логика и
расположение элементов интерфейса не менялись.

## Главное

- стабильные пространства данных, настроек и паролей для следующих бета-версий;
- автоматическая миграция данных из 1.0.0-beta1 и 1.0.1-beta;
- единый RCI-транспорт для запросов к роутеру;
- меньше повторных запросов при автообновлении и полный обход кэша вручную;
- типизированный результат изменяющих операций с совместимостью старого UI;
- удаление подтверждённо неиспользуемого кода;
- обязательные Ruff, 425 автоматических тестов и контроль покрытия перед сборкой.

## Обновление

Перед созданием патча или Windows-сборки установите зависимости разработчика:

```powershell
python -m pip install -r requirements-dev.txt
```

Сборщики запускают проверку качества автоматически. При первом запуске новой
бета-версии прежняя база выбирается по времени изменения и копируется только
если целевое хранилище ещё не создано. Существующие данные не перезаписываются.
