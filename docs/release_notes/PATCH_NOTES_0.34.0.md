# Keenetic Manager 0.34.0

## PriorityService

В новый `core/services/priority_service.py` вынесены:

- чтение `show/sc/interface`;
- единый `PrioritySnapshot`;
- извлечение `ip.global.order`;
- определение основного и резервных каналов;
- нормализация пропусков и дубликатов порядка;
- вставка и исключение интерфейса из порядка;
- добавление настроенных, но временно отсутствующих каналов;
- сортировка карточек по глобальному порядку;
- пакетная запись порядка и сохранение конфигурации;
- проверка применённого порядка;
- отдельный журнал изменения приоритетов.

`KeeneticClient` сохраняет совместимые фасады. `WiredInternetService`,
`WirelessIspService` и `ConnectionWorker` обращаются к сервису напрямую.

Схема SQLite остаётся 280.
