# Keenetic Manager 1.0.11-beta

Стабильная техническая контрольная точка в ходе разработки.

## Изменения

- жизненный цикл подключений вынесен из главного окна в отдельный контроллер;
- быстрые переключения не смешивают результаты разных роутеров;
- старый монитор удерживается до полного завершения `QThread`;
- временный обрыв не очищает последний подтверждённый рабочий снимок;
- закрытие окна остаётся неблокирующим во время сетевого запроса;
- добавлен обезличенный read-only профиль реального Sprinter KN-3711;
- комплект расширен до 567 тестов, общее покрытие составляет 47%.

## Совместимость и безопасность

Расположение элементов, кнопки и форматы сохранённых данных не менялись.
Проверка реального роутера использовала только чтение RCI. Фикстура не содержит
адресов, SSID, MAC-адресов, имён клиентов или учётных данных.
