# Keenetic Manager 0.35.6

- Устранён вредный автоматический откат успешной команды `mws.wlan.enable`,
  когда Keenetic обновляет saved/runtime MWS асинхронно.
- Проверка переключения принимает как сохранённое состояние, так и фактическое
  runtime-состояние диапазонов.
- Если RCI-команда принята, но чтение ещё не синхронизировалось, операция
  считается принятой и завершается обычным фоновым обновлением.
- Диагностический ZIP теперь включает снимки `show/sc/mws/wlan`,
  `show/mws/wlan` и событие переключения без паролей.
- Схема базы данных остаётся 280.
