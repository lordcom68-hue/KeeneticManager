# Keenetic Manager 0.28.0 — порядок роутеров перетаскиванием

## Что изменилось

- Перед каждой строкой роутера появилась отдельная шеститочечная ручка.
- Перетаскивание начинается только при захвате этой ручки; обычный клик по строке лишь выбирает роутер.
- Новый порядок сразу сохраняется в SQLite в колонке `sort_order`.
- После перезапуска приложения порядок восстанавливается без сортировки по имени.
- Новые роутеры добавляются в конец списка.
- После удаления роутера порядок автоматически уплотняется до непрерывного ряда `0..N-1`.
- Во время поиска drag-and-drop отключён, чтобы отфильтрованный неполный список нельзя было сохранить как полный порядок.
- Схема SQLite повышена с `270` до `280`.

## Миграция

Для существующей базы 0.27.0 колонка `sort_order` создаётся автоматически. Первый порядок формируется из прежнего алфавитного отображения, поэтому сразу после обновления список выглядит так же, как до обновления.

## Безопасность

Изменение порядка не читает пароли и не обращается к Windows Credential Manager. В базе меняются только целочисленные значения `sort_order`.
