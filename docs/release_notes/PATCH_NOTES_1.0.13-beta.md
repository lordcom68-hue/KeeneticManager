# Keenetic Manager 1.0.13-beta

Стабильная контрольная версия в ходе разработки, посвящённая архитектурной
уборке без изменения пользовательского интерфейса и поведения роутеров.

## Что изменилось

- обработка 25 команд роутера разделена на независимые обработчики;
- крупные действия интернет-подключений вынесены из главного окна;
- устранено дублирование PPPoE/PPTP/L2TP;
- чтение Wi-Fi отделено от изменяющих операций;
- добавлены неизменяемые модели Wi-Fi и типизированная очередь действий;
- удалены только подтверждённо неиспользуемые фасады клиента;
- CI запускает качество и проверяет чистую portable-сборку на Windows;
- release-зависимости закреплены точными версиями.

## Проверка

- 701 автоматический тест;
- Ruff без замечаний;
- общее покрытие — 57%;
- каждый архитектурный этап зафиксирован отдельным Git-коммитом и проходил
  полный регрессионный набор.

## Совместимость

Пользовательские данные, пароли и профили хранения не менялись. Публичные
команды, используемые интерфейсом, сохранены; изменения затрагивают внутреннюю
структуру приложения.
