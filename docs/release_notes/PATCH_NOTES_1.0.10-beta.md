# Keenetic Manager 1.0.10-beta

Стабильная техническая контрольная точка в ходе разработки.

## Изменения

- самопроверка и её история управляются отдельным UI-контроллером;
- read-only мониторинговый снимок собирается отдельным сервисом с
  централизованным кэшем;
- удалён неиспользуемый прежний путь кэширования в `KeeneticClient`;
- добавлена синтетическая обезличенная фикстура KeeneticOS;
- усилены тесты планировщика, read-only действий и завершения потоков;
- полный и частичный циклы проверены на Sprinter KN-3711 без изменения
  конфигурации роутера;
- полный комплект содержит 555 тестов, общее покрытие проекта — 46%,
  сервиса обновления — 95%, сервиса самопроверки — 91%.

## Совместимость и безопасность

Поведение кнопок и форматы существующих отчётов сохранены. Реальная проверка
использовала только чтение RCI. Фикстура не содержит настоящих сетевых адресов,
MAC-адресов, имён пользователей или учётных данных.
