# Keenetic Manager 0.35.5

- Сохранённое `mws.wlan.enable` стало источником состояния ползунка.
- Runtime диапазонов больше не отменяет успешное переключение во время задержки применения.
- При создании сеть всегда получает явное `enable: true/false`.
- Список сетей и диапазонов полностью перестраивается по актуальным MWS-профилям и назначенным AccessPoint.
- Удалённые через веб-интерфейс MWS-профили удаляются из внутреннего кэша.
- Карточки используют стабильный ключ `mws_profile_id`.
- Схема базы данных остаётся 280.
