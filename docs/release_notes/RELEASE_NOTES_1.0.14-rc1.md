# Keenetic Manager 1.0.14-rc1

Первый релиз-кандидат ветки 1.0.14. Набор функций заморожен;
дальнейшие изменения до стабильного выпуска ограничены исправлениями.

## Главное

- три режима Wireless ISP/Wi-Fi: «Спасатель», «Спасаемый» и
  «Смешанный»;
- передача сессии между локальным HTTP и KeenDNS HTTPS;
- управление MWS-сетями с WPA2, WPA2/WPA3, WPA3, OWE и открытым
  режимом;
- безопасное изменение и удаление системного профиля `DEFAULT__`;
- восстановление Dedicated WAN и проверка состояния после команд;
- очищенные диагностические архивы без паролей и токенов.

## Проверка

- ручной сеанс на Keenetic Sprinter KN-3711 с KeeneticOS 5.1.1 завершён
  без критических ошибок;
- Wi-Fi MWS, Dedicated WAN, «Спасатель» и «Смешанный» подтверждены;
- после ожидаемого обрыва KeenDNS локальная HTTP-сессия
  восстановилась автоматически.

## Совместимость

RC использует тот же beta-профиль хранения. Сохранённые роутеры,
настройки и учётные данные предыдущей beta-версии будут подхвачены
автоматически.

## Статус

Это предрелизная сборка. При обнаружении дефекта следует приложить
диагностический ZIP-архив.
