# Keenetic Manager 0.28.1 — исправление списка роутеров

- Шеститочечные ручки постоянно подсвечены у всех роутеров, а не только у выбранного.
- Перенос на верхнюю или нижнюю половину строки преобразуется в безопасную вставку до или после роутера.
- Элементы списка больше не являются прямыми drop-целями, поэтому строка не может временно исчезнуть.
- Перемещение выполняется контролируемо через take/insert с проверкой неизменности количества роутеров.
- Порядок SQLite и схема 280 не изменяются.
