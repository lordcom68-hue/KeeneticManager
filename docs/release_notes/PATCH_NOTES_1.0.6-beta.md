# Keenetic Manager 1.0.6-beta

Стабильная контрольная точка в ходе разработки, добавляющая постоянную историю
операций с Ethernet-портами и read-only проверку совместимости KeeneticOS.

## Изменения

- операции портов отображаются рядом с системными событиями во вкладке
  «Журнал»;
- история разделена по роутерам и сохраняется после перезапуска приложения;
- подтверждение, отказ, откат и частичный результат получают разные уровни;
- при отсутствии `show log` локальные события приложения остаются доступны;
- история ротируется, очищается от чувствительных данных и попадает в
  диагностический архив;
- повторная одинаковая команда порту блокируется на две секунды;
- по сохранённым снимкам без изменения роутеров проверены KeeneticOS 4.03,
  5.00 и 5.01, FastEthernet и GigabitEthernet.

Проверка версии: Ruff, 474 автоматических теста, общее покрытие 43%, покрытие
`OperationHistoryService` 87% и `PortStatusService` 89%.
