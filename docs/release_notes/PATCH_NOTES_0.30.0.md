# Keenetic Manager 0.30.0

## InterfaceService

Из `KeeneticClient` вынесены:

- чтение `show/interface`;
- чтение `show/sc/interface`;
- единый `InterfaceSnapshot`;
- проверка `enabled` и `up`;
- нормализация статистики;
- получение статистики интерфейса;
- включение и выключение;
- подтверждение административного состояния;
- переподключение `down → up`;
- выбор слоя интерфейса для трафика.

`KeeneticClient` сохраняет совместимые методы-фасады, поэтому GUI,
`RouterMonitor` и `ConnectionWorker` продолжают использовать прежний API.

Схема SQLite остаётся 280. Поведение интерфейса приложения не меняется.
