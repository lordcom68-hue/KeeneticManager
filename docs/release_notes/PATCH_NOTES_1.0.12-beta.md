# Keenetic Manager 1.0.12-beta

Стабильная контрольная версия в ходе разработки, посвящённая защите от
аварий, отзывчивости больших журналов и повторяемой проверке готовых сборок.

## Что изменилось

- необработанные исключения и сбои фоновых потоков сохраняются в
  ротируемый обезличенный журнал;
- включён отдельный низкоуровневый журнал фатальных ошибок Python;
- аварийные файлы автоматически попадают в диагностический архив;
- быстрый поиск по большому журналу больше не запускает полную перерисовку
  после каждой буквы;
- portable и установщик проходят автоматический изолированный smoke-тест,
  не закрывающий запущенную программу и сохраняющий существующую запись
  удаления в реестре;
- добавлены стресс-сценарии переподключения, временных отказов и серии
  запросов обновления;
- комплект содержит 580 тестов, общее покрытие проекта — 47%, обязательный
  порог проверки повышен до 45%.

## Длительная проверка

На реальном KN-3711 выполнен 30-минутный тест только для чтения: 178 из 178
циклов успешны, 14 локальных переподключений сессии, средний ответ 0,152 с,
`p95` — 0,373 с. Настройки роутера не изменялись.

## Безопасность

Аварийная диагностика очищает секретные поля и данные авторизации. Проверка
реального роутера использует только чтение; конфигурация устройства не
изменяется.
