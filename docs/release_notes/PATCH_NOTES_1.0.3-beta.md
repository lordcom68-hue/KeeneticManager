# Keenetic Manager 1.0.3-beta

Стабильная контрольная точка в ходе разработки, посвящённая обработке трафика
и графикам. Расположение карточек и логика управляющих кнопок не изменялись.

## Изменения

- добавлен единый `TrafficService` для интернет-подключений и клиентов;
- исправлен расчёт при быстрых и неравномерных циклах автообновления;
- сброс или отсутствие одного счётчика не обнуляет второе направление;
- невозможные пики фильтруются с учётом физической скорости интерфейса;
- распознаются числовые, английские и русские единицы скорости;
- со всех графиков полностью удалена заливка, включая неявную заливку Qt;
- покрытие проекта поднято до 41%, новый сервис покрыт на 87%.

Проверка версии: Ruff, 434 автоматических теста, coverage и контроль
целостности сборочных сценариев.
