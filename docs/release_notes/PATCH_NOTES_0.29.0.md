# Keenetic Manager 0.29.0

- Локальный IP и KeenDNS отображаются в шапке выбранного роутера.
- Ссылки доступны даже при отключённом роутере.
- Локальный IP по умолчанию открывается через `http://`.
- KeenDNS по умолчанию открывается через `https://`.
- Явно указанные `http://` и `https://` сохраняются.
- Адреса можно выделять, копировать через Ctrl+C и контекстное меню.
- Правый клик предоставляет команды «Открыть в браузере» и
  «Копировать адрес».
- IPv6-хост автоматически заключается в квадратные скобки.
- Схема базы остаётся 280.
