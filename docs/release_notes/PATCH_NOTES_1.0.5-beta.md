# Keenetic Manager 1.0.5-beta

Стабильная контрольная точка в ходе разработки, посвящённая безопасному
управлению физическими Ethernet-портами на KeeneticOS 4 и 5.

## Изменения

- добавлен типизированный `PortStatusService`;
- физический линк отделён от административного состояния порта;
- исправлен выбор полной runtime-записи при дублировании порта в RCI;
- выключение текущего порта управления блокируется в UI и ядре;
- неподтверждённое переключение автоматически возвращает исходное состояние;
- восстановление выключенного порта доступно даже без карточки клиента;
- кнопки защищены от повторного нажатия до подтверждения результата;
- защищённый порт отмечается в подсказке схемы портов;
- операции с Ethernet-портами добавлены в диагностические события;
- Ruff теперь проходит для всего репозитория без исключений по старому
  smoke-скрипту.

Проверка версии: Ruff, 465 автоматических тестов, общее покрытие 43%, покрытие
нового сервиса 89% и контроль целостности сборочных сценариев.
