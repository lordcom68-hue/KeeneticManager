# Keenetic Manager 1.0.8-beta

Стабильная контрольная точка в ходе разработки с безопасной самопроверкой
подключённого роутера.

## Возможности

- отдельная проверка локального HTTP и KeenDNS HTTPS;
- подтверждение авторизации и read-only RCI для каждого настроенного канала;
- измерение времени ответа и выделение запросов дольше шести секунд;
- контроль полного обновления, системных данных, подключений, клиентов, Wi-Fi,
  Ethernet-портов, профиля совместимости и системного журнала;
- понятные статусы для успешных, проблемных, ошибочных и неприменимых тестов;
- копирование текстового отчёта и экспорт обезличенного JSON;
- сохранение последней сводки в диагностическом архиве.
- отсутствие необязательных компонентов USB и VPN не считается проблемой
  совместимости; отчёт перечисляет конкретные ограниченные и недоступные
  функции.

## Безопасность

Самопроверка не отправляет изменяющие RCI-команды. Пробные HTTP-сессии не
заменяют основную сессию мониторинга и не добавляются в постоянную историю
подключений. В отчёте отсутствуют адреса, имена роутеров и учётные данные.
