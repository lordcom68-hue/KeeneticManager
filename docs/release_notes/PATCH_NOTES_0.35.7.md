# Keenetic Manager 0.35.7

- Исправлено ложное подтверждение включения, когда `show/sc/mws/wlan`
  уже содержит `enable=true`, но все runtime-диапазоны всё ещё выключены.
- Для фактического состояния карточки runtime MWS имеет приоритет над
  сохранённым флагом, если Keenetic уже вернул данные диапазонов.
- Добавлено безопасное одноразовое восстановление AccessPoint-интерфейсов,
  которые старые версии приложения оставили без административного `up`.
- При выключении физические интерфейсы отдельно не трогаются.
- После любой Wi‑Fi-операции немедленно запрашивается свежий снимок роутера.
- Схема базы данных остаётся 280.
