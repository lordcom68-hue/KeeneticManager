# Keenetic Manager 0.35.0

## WiFiNetworkService — первый этап Wi‑Fi-модуля

- Добавлен отдельный верхний раздел **«Wi‑Fi»** сразу после **«Интернет»**.
- Добавлен `core/services/wifi_network_service.py`.
- Чтение Wi‑Fi-сетей, сохранение выключенных сетей и расчёт активности клиентов вынесены из `KeeneticClient`.
- Одинаковый SSID на 2,4/5/6 ГГц объединяется в одну логическую сеть с отдельным состоянием каждого диапазона.
- Реализовано создание дополнительной Wi‑Fi-сети на одном или нескольких доступных диапазонах.
- Реализованы переименование, изменение WPA2-пароля, переключение открытой/WPA2-сети и скрытие SSID.
- Реализовано общее включение/выключение сети через существующий безопасный интерфейсный сервис.
- Реализовано удаление дополнительных точек доступа.
- Основная и гостевая системные сети защищены от удаления; их можно изменить или выключить.
- Выключенные настроенные сети не исчезают из «Мои сети и Wi‑Fi».
- В мониторинге добавлена кнопка удаления для сетей, которые разрешено удалять.
- Добавлена защита от создания или переименования в уже занятый SSID.
- `ConnectionWorker` направляет операции создания, изменения и удаления напрямую в `WiFiNetworkService`.
- В `KeeneticClient` сохранены короткие совместимые фасады.

## Ограничение первого этапа

Добавление или удаление отдельного диапазона у уже существующей сети пока отключено в окне редактирования. Сначала проверяется безопасное создание новых сетей на реальных моделях Keenetic. Создать новую сеть сразу на 2,4 и 5 ГГц уже можно.

## Совместимость

- Схема базы данных остаётся `280`.
- Рабочие `database`, `logs` и `diagnostics_history` не требуют изменений.
