# Keenetic Manager 0.35.2

## Исправлено

- Переименование MWS-управляемой Wi-Fi-сети теперь синхронизирует
  логический профиль Keenetic (`show/sc/mws/wlan`) и связанные
  физические `WifiMaster*/AccessPoint*`.
- Логический профиль определяется по runtime-карте
  `show/mws/wlan -> band -> access-point`, а не по имени SSID.
- Для записи используется частичный RCI-объект `mws.wlan`:
  обновляются только `id`, `ssid.name`, `ssid.hide` и, при явной
  смене пароля, `wpa.psk`. Остальные параметры профиля не
  пересоздаются и не сбрасываются.
- После записи проверяются:
  - SSID физических точек доступа;
  - `ssid.name` логического профиля;
  - сохранность связи профиля с теми же AccessPoint-интерфейсами.
- При частично выполненном изменении выполняется автоматический
  откат обоих слоёв.
- Переименование системной сети блокируется до отправки команд,
  если её MWS-профиль не найден.
- Диалог различает фактическую смену режима безопасности и простое
  сохранение формы, чтобы не понижать WPA2/WPA3 до WPA2 без
  явного действия пользователя.
- Схема базы остаётся 280.

## Ограничение

Переключение существующей MWS-сети из WPA в полностью открытую сеть
временно блокируется до отдельной проверки точной команды удаления
WPA-параметров. Переименование, скрытие SSID и смена пароля
поддерживаются.
