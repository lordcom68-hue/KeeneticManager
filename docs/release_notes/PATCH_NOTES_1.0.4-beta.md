# Keenetic Manager 1.0.4-beta

Стабильная контрольная точка в ходе разработки, посвящённая системным данным
роутера. Интерфейс, расположение элементов и управляющие команды не менялись.

## Изменения

- добавлен типизированный `SystemStatusService`;
- объединено извлечение модели и версии из разных форматов KeeneticOS;
- нормализованы uptime, CPU и показатели памяти;
- сохранён точный расчёт занятой памяти с учётом штатной пары `used/total`;
- добавлена защита обновления от повреждённых, бесконечных и пустых значений;
- старые методы `KeeneticClient` оставлены совместимыми фасадами;
- покрытие проекта повышено до 42%, нового сервиса — до 97%.

Проверка версии: Ruff, 445 автоматических тестов, coverage и контроль
целостности сборочных сценариев.
