# Keenetic Manager 0.35.11 — стабильная версия в ходе разработки

- Статус: `stable`.
- Канал: `development`.
- Это стабильная контрольная точка текущей разработки, а не финальная сборка.

## Надёжность и безопасность

- База роутеров, журналы и диагностическая история теперь находятся в каталоге
  данных пользователя `%LOCALAPPDATA%\KeeneticManager`, а не среди исходников.
- Существующая `database\routers.db` переносится безопасным однократным
  копированием. Уже существующая целевая база не перезаписывается.
- Журнал блокировки `show/hardware` очищает пароли, токены, ключи и учётные
  данные из URI до записи на диск.
- Устранён циклический импорт `core.services` без удаления публичных экспортов.

## Очистка проекта

- Удалён неиспользуемый `core/rci/redaction.py`; используется единый проверенный
  механизм `core.rci.diagnostics.sanitize_value`.
- Удалены подтверждённо неиспользуемые импорты и глобальное отключение
  TLS-предупреждений.
- Исторические `PATCH_NOTES` собраны в `docs\release_notes`; в корне остаются
  только заметки текущего патча.
- `urllib3` убран из прямых зависимостей; для остальных библиотек заданы
  совместимые диапазоны версий.
- Добавлен `README.md` с актуальными командами установки и запуска.
- Добавлен `tools\build_clean_backup.ps1` для одинаковой сборки папки и ZIP
  чистого проекта без пользовательских данных.

## Патчи

- Пакет теперь содержит полный набор исходников, интерфейса, тестов, инструментов
  и документации вместо шести жёстко заданных файлов.
- Runtime-данные, кэши и временные файлы в пакет не попадают.
- Манифест поддерживает безопасное удаление устаревших файлов.
- При ошибке установщик откатывает обновления и удаления, а перед завершением
  запускает весь комплект тестов.

## Проверка

- Проверяется полная автоматическая регрессия проекта.
- Добавлены тесты однократной миграции базы и маскировки секретов в журнале.
