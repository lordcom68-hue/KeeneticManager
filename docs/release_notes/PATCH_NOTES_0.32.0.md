# Keenetic Manager 0.32.0

## WirelessIspService

В `core/services/wireless_isp_service.py` физически перенесены:

- распознавание Wireless ISP 2,4/5 ГГц;
- проверка настроенного профиля WifiStation;
- обогащение карточек подключения;
- нормализация диапазона;
- разбор `show site-survey`;
- сканирование доступных сетей;
- проверка SSID и пароля;
- создание Wireless ISP;
- откат незавершённого создания;
- проверка применённой конфигурации;
- изменение SSID, BSSID и безопасности;
- удаление Wireless ISP.

`KeeneticClient` сохраняет короткие совместимые фасады.
`ConnectionWorker` выполняет scan/create/delete через сервис напрямую.
Обновление общих параметров интерфейса также вызывает сервис напрямую.

Схема SQLite остаётся 280. Форматы GUI-сигналов не меняются.
