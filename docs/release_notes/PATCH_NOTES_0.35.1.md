# Keenetic Manager 0.35.1

## Исправление переименования Wi-Fi-сети

- Кэш выключенных Wi-Fi-сетей теперь привязан к стабильным интерфейсам точки доступа, а не к SSID.
- После переименования старое имя больше не остаётся в приложении второй выключенной карточкой.
- Карточки в верхней вкладке «Wi-Fi» и в «Мои сети и Wi-Fi» сохраняют идентичность при смене SSID и обновляются без пересоздания.
- Перед изменением проверяется, что все редактируемые интерфейсы действительно существуют и уже имеют настроенный SSID.
- Если интерфейс устарел или исчез, операция прекращается до отправки команд и не может случайно создать новую точку доступа.
- После успешного изменения или удаления очищаются только кэшированные записи с теми же интерфейсами.

## Совместимость

- Схема базы данных остаётся `280`.
- `database`, `logs` и `diagnostics_history` не изменяются.
