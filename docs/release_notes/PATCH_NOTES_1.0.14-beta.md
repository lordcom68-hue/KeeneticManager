# Keenetic Manager 1.0.14-beta

Стабильная контрольная версия в ходе разработки, посвящённая безопасному
переключению режимов Wireless ISP/Wi-Fi и восстановлению мониторинга после
смены канала управления.

## Что изменилось

- добавлен третий режим «Смешанный»: WISP и Wi-Fi включены одновременно;
- реализовано переподключение между локальным HTTP и KeenDNS HTTPS;
- команды управления ожидают активную сессию и не запускают ложный откат;
- состояние «Остановка мониторинга…» больше не остаётся после завершения;
- повторное подключение, запрошенное во время остановки, продолжается
  автоматически;
- расширена очистка чувствительных полей диагностического архива;
- команда создания Wi-Fi сети адаптируется к доступным полям MWS конкретной
  модели и версии KeeneticOS, не вызывая `no input` на KN-3711;
- открытые сети передаются в KeeneticOS как `encryption: none`, а не как
  внутреннее значение интерфейса `open`;
- создание MWS-сетей поддерживает WPA2-PSK, WPA2/WPA3-PSK, WPA3-SAE, OWE
  и открытую сеть без добавления устаревших WEP/WPA;
- эти же режимы доступны при редактировании MWS-сети, а фактически
  сохранённый тип защиты проверяется с автоматическим откатом при отказе;
- при смене защиты сохраняется полный MWS-профиль без конфликтующих команд
  физических точек доступа, что исправляет переходы в WPA3, OWE и открытую
  сеть на KeeneticOS 5.01;
- открытый режим при редактировании теперь удаляет сохранённые команды
  `encryption` и `wpa psk` штатными RCI-маркерами KeeneticOS;
- для системного профиля `DEFAULT__` разрешены изменение диапазонов и
  удаление с отдельным предупреждением, как в веб-интерфейсе Keenetic.

## Проверка

- 726 автоматических тестов;
- Ruff без замечаний;
- общее покрытие — 58%;
- вручную подтверждены переходы между тремя режимами и восстановление связи.

## Статус

Это стабильная версия в ходе разработки. Пространства хранения базы,
настроек и учётных данных совместимы с предыдущими beta-версиями.
