# Дорожная карта Keenetic Manager

Здесь разделены подтверждённые ближайшие задачи и возможные направления
развития. Порядок может меняться после тестирования на реальных устройствах и
обратной связи пользователей; для пунктов без версии даты выпуска не обещаны.

## Сейчас: стабилизация 1.0.14

- [x] Выпустить публичный релиз-кандидат `1.0.14-rc1`.
- [x] Подготовить установщик, portable-архив, архив исходников и контрольные
  суммы SHA-256.
- [x] Проверить Ruff, полный набор из 738 тестов и Windows CI.
- [x] Проверить основные сценарии на Keenetic Sprinter KN-3711 с
  KeeneticOS 5.1.1.
- [ ] Собрать обратную связь по релиз-кандидату и исправить найденные дефекты.
- [ ] Расширить ручную проверку на других моделях и версиях KeeneticOS.
- [ ] Уточнить таблицу совместимости функций для проверенных устройств.
- [ ] Выпустить стабильную `1.0.14`, если не останется блокирующих ошибок.

На этапе RC новые крупные функции не добавляются: это снижает риск регрессий
перед стабильным выпуском.

## После стабильной 1.0.14

Ближайшие направления, которые планируется проработать:

- улучшение сообщений об ошибках и рекомендаций по восстановлению соединения;
- расширение профилей совместимости старых и новых версий KeeneticOS;
- дополнительные тестовые сценарии для обновления KeeneticOS и передачи
  сессии между локальным адресом и KeenDNS;
- развитие журнала операций и диагностических отчётов;
- улучшение доступности интерфейса и поведения на разных масштабах Windows;
- упрощение подготовки воспроизводимых подписанных Windows-релизов.

## Идеи на будущее

Эти пункты рассматриваются, но пока не назначены на конкретный выпуск:

- встроенная проверка новых версий самого Keenetic Manager;
- графики и история сетевого трафика;
- экспорт и импорт пользовательских настроек приложения;
- расширенный отчёт о совместимости роутера перед изменяющими операциями;
- дополнительные языки интерфейса;
- цифровая подпись готовых Windows-сборок.

## Как повлиять на приоритеты

При сообщении об ошибке полезно указать модель роутера, версию KeeneticOS,
сценарий воспроизведения и приложить обезличенный диагностический ZIP из
приложения. Пароли, токены, публичные адреса и другие секреты публиковать не
следует.

Предложения и отчёты можно создавать в разделе
[Issues](https://github.com/lordcom68-hue/KeeneticManager/issues).
