# Оценка keenetic-sdk для Keenetic Manager

## Что это за репозиторий

`keenetic-sdk` — система сборки KeeneticOS на базе OpenWrt.

Основные разделы:

- `config` — конфигурация сборки;
- `docs` — документация OpenWrt по сборочной системе;
- `include` — make-файлы и интеграция библиотек/компонентов;
- `package` — пакеты и компоненты прошивки;
- `target` — платформы;
- `toolchain` — инструментарий сборки.

## Чем полезен проекту

SDK можно использовать для:

1. поиска названий компонентов KeeneticOS;
2. определения зависимостей компонентов;
3. понимания доступности USB, storage, VPN и сетевых модулей;
4. сопоставления `ndw.components` с функциями устройства;
5. исследования библиотек `libndm` и механизмов сборки NDM-компонентов.

## Чего в открытом SDK не обнаружено

В открытой структуре не найден готовый полный справочник HTTP RCI:

- нет публичной схемы всех `show/...`;
- нет гарантированной JSON-схемы `show/sc/interface`;
- нет таблицы совместимости RCI по моделям и версиям;
- нет готового описания команд конфигурирования веб-интерфейса.

Поэтому SDK нельзя использовать как единственный источник схем RCI.

## Стратегия исследования

Для каждой функции фиксируются три источника:

1. **Ответ роутера** — фактическая структура RCI.
2. **Запрос официального веб-интерфейса** — фактическая команда записи.
3. **SDK** — наличие компонента и технический контекст.

Команда считается подтверждённой только после наблюдения на реальном
роутере или в официальном интерфейсе.

## Статусы знаний

- `verified` — подтверждено реальным ответом/запросом;
- `observed` — встречалось на одной модели;
- `inferred` — логический вывод, требует проверки;
- `unsupported` — endpoint отсутствует на конкретном роутере.
