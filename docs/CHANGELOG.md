## 1.0.4-beta — единое системное состояние

- Извлечение модели, версии KeeneticOS, времени работы, загрузки CPU и памяти
  вынесено из `KeeneticClient` в отдельный типизированный
  `SystemStatusService`.
- Разные формы ответов старых и современных версий KeeneticOS нормализуются в
  один неизменяемый `SystemStatus`, не затрагивая существующий UI.
- Для памяти сохранён приоритет прямого процента, затем штатного значения
  `used/total` и безопасного резервного расчёта с учётом буферов и кэша.
- Некорректные `NaN`, бесконечные и отрицательные значения больше не способны
  сорвать обновление карточки устройства.
- Публичные методы `KeeneticClient` сохранены как совместимые фасады, поэтому
  существующие сервисы, тесты и интерфейс не требуют миграции.
- Минимальное покрытие проекта повышено и закреплено на 42%; новый сервис
  покрыт тестами на 97%.

## 1.0.3-beta — единая обработка трафика

- Расчёт скоростей интернет-подключений вынесен из `KeeneticClient` в
  отдельный типизированный `TrafficService`.
- Wi-Fi- и Ethernet-клиенты используют тот же расчёт байтовых счётчиков, что
  устраняет разные результаты для карточек клиентов и графиков.
- Быстрое повторное обновление больше не сдвигает базовую точку измерения;
  длинный интервал, сброс одного направления и невозможный пик обрабатываются
  независимо и не повреждают второй поток.
- Все подключения одного снимка получают одну временную метку, а повторная
  отрисовка кэшированного результата не добавляет ложную точку на график.
- Убрана явная и неявная заливка графиков: Qt рисует только линии, конечные
  точки и сетку.
- Добавлены тесты реального рендеринга графика, неравномерных интервалов,
  сбросов, пределов физической скорости и локализованных единиц измерения.

## 0.35.9 — стабильная версия разработки

- Версия отмечена как `stable` в канале `development`; это стабильная
  контрольная точка разработки, а не финальный релиз.

- Исправлено подтверждение переключения Wi-Fi между сохранённым MWS,
  runtime MWS и физическими AccessPoint-интерфейсами.
- Отсутствующие runtime-данные больше не считаются автоматически состоянием
  «выключено»; для проверки дополнительно используется конфигурация интерфейса.
- Итоговая проверка использует список AccessPoint, сохранённый до переключения,
  и требует ожидаемого физического состояния для всех точек сети.
- На KeeneticOS 5.01 runtime MWS может сохранять предыдущее значение после
  успешного переключения; при известных AccessPoint он используется только
  для диагностики и не создаёт ложную ошибку.
- Исправлено выключение физических AccessPoint после переименования сети:
  транзакция сохраняет и восстанавливает состояние каждого диапазона всех
  MWS-профилей, а затем проверяет одновременно новый SSID и фактическое
  состояние изменяемой и соседних сетей.
- Переименование второй сети больше не выключает первую сеть при общем
  перезапуске беспроводной конфигурации KeeneticOS.
- Откат неудачного редактирования также возвращает исходные `up/no up`.
- В диагностический архив добавляется событие `wifi_mws_update` с результатом
  проверки и сохранёнными состояниями AccessPoint.
- Неподтверждённая команда больше не показывается приложением как успешная.
