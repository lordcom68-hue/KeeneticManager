# Keenetic Manager 1.0.0-beta1

- Статус: `beta`.
- Канал: `beta`.
- Это первый бета-выпуск перед финальной версией 1.0.0.

## Основные изменения

- Завершены основные сценарии мониторинга и управления несколькими роутерами.
- Реализовано управление Wi-Fi-сетями для современных MWS-роутеров и отдельный
  legacy-режим KeeneticOS 4.
- Завершена вкладка клиентов Wi-Fi и Ethernet с фильтрами, подробностями и
  безопасным отключением клиентов.
- Унифицирован интерфейс, добавлены фирменная иконка и запуск главного окна в
  развёрнутом состоянии.
- Переработаны графики скорости и исправлена обработка сетевых счётчиков.
- Улучшены автообновление, подключение по HTTP/HTTPS, диагностика и журнал.

## Состояние выпуска

Функциональность готова к бета-тестированию. Перед финальным выпуском 1.0.0
необходимо проверить сборку на чистой системе Windows и на поддерживаемых
версиях KeeneticOS.
